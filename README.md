# Workscope — поиск заказов для фриланса

React + Vite приложение для поиска, фильтрации и сохранения фриланс-проектов.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сейчас интерфейс работает на демонстрационной подборке. Реальные заказы требуют подключения API площадок или backend-сервиса.
