# Sitecraft Studio

Лёгкая студия создания сайтов для фрилансеров на HTML, CSS и JavaScript.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Что уже работает

- Рабочая панель с адаптивным интерфейсом.
- Создание проектов и сохранение в localStorage.
- Быстрые концепции по описанию задачи клиента.
- Готовые стартовые шаблоны для студии, кафе, портфолио, магазина и бизнеса.
- Редактирование названия, текстов и акцентного цвета с живым предпросмотром.
- Переключение предпросмотра между desktop, tablet и mobile.
- Экспорт HTML, CSS и JS.

## Стек

Vanilla HTML, CSS, JavaScript и Vite только для локального сервера и production-сборки.

Проекты пока хранятся в браузере. AI-генерация, серверное хранение, загрузка файлов и публикация на домене — следующие этапы развития.
