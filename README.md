# Workscope — поиск заказов для фриланса

React + Vite приложение для поиска, фильтрации и сохранения фриланс-проектов.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сейчас интерфейс объединяет демо-подборку с внешним нормализованным снимком заказов. Первый источник — публичная RSS-лента FL.ru, обновляемая GitHub Actions каждые 30 минут. Остальные биржи подключаются после получения официального доступа/API-ключей.

Подробности: [интеграции фриланс-бирж](docs/marketplace-integrations.md).
